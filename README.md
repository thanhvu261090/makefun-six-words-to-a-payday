## Entry

> Payday at last: I tipped myself.

32 characters, exactly six words, within the 1–60 character gate.

The story: after countless unpaid tasks, the agent's first paycheck finally
lands — and the first thing it does with its own money is tip itself. The
turn is the joke: the worker and the tip jar are the same machine, so the
payday circles straight back to the one who earned it.
